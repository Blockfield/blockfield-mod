# Происхождение ресурсов

Перенос 2026-09-30 использует опубликованные Elite X bf9 и TACZ bf7, уже
закреплённые клиентом. Отобраны только анимации и OGG, байты которых отличаются
от соответствующего проверенного upstream: Elite X **21 JSON + 36 OGG**,
TACZ **53 JSON + 59 OGG**. Изначальный объём — **29 542 997 байт**.

| Вход                                  | SHA256                                                             |
| ------------------------------------- | ------------------------------------------------------------------ |
| Elite X Fabric 4.2.1 upstream         | `cf6981d3e4bb416f71931885ef95f0eb5b2d40798888929c014b0a50b44b9bbc` |
| Elite X bf9                           | `0118b94b6f3f587dcd14c9366f56a739f1448adb34848c6d8366b124853e6acc` |
| TACZ 0.7.0-forge1.1.8-hotfix upstream | `997eaab4f2a1374e7b546aeec63be8bd071c933fc0aa8982cd99e282f7375b31` |
| TACZ bf7                              | `d00089bba66446ecc04a400888f6771b7ee0a5269c4632902feb2f96426d7445` |

Физические имена Minecraft сохранены. При переносе убраны только упаковочные
префиксы `assets/elitex/custom/elitex_quality_guns/` и
`assets/tacz/custom/tacz_default_gun/`; остаются `assets/<namespace>/animations/`
и `assets/<namespace>/tacz_sounds/`. JSON отформатированы без изменения объектов
анимаций; OGG совпадают с опубликованными JAR побайтно. Данные оружия, индексы,
модели и текстуры не копируются.

Исходные рецепты — `Blockfield/elite-x/scripts/patch.py` и
`Blockfield/tacz-refabricated/scripts/patch.py`; общий инструмент
`Blockfield/elite-x/scripts/animsync.py` выполняет подгонку времени при сборке,
а не во время игры. Изменение серверного `draw_time` само по себе не растягивает
эти анимации или звук.

Пак поставляется только внутри клиентского JAR и регистрируется как Fabric
`ALWAYS_ENABLED`. Общие JAR, рецепты и пины этим переносом не меняются.
Проверка фактического приоритета встроенного пака проводится отдельно на стенде.

## Хват гранат LR Tactical

Клиентская подгонка 2026-10-03 использует закреплённый LR Tactical Fabric bf2
`lrtactical-1.21.1-0.4.1-bf2.jar`, SHA256
`c31b4d222b3bad9dcc39fc81266c4d17b3c80fec342ff02de591225c9f45909e`.
Исходные пути `assets/lrtactical/animations/throwable/{m67_grenade,rgn_grenade,
smoke_grenade,flash_grenade}.animation.json` сохранены.

Изменены только трансформации рук: убрано растяжение Y, компенсирован кончик
native руки и опущена правая ладонь к нижней части корпуса, чтобы перчатка
не закрывала гранату. У дымовой правая ладонь поднята на 2,5 модельных пикселя
относительно этой подгонки, чтобы охватывать нижнюю часть корпуса, а не
оставаться под ним; смещение одинаково во всех клипах. Свободная левая рука в покое опущена; исходные ключи
контакта с чекой сохранены, начальный ключ поднимает руку из нового idle.
Исходные корпус, чека, камера, звуки, длительности,
state machine и серверные данные сохранены. Molotov использует исходную
`m67_grenade` анимацию и получает ту же подгонку хвата. Геометрия и текстуры
не копируются; они остаются в закреплённом LR JAR. Лицензия и авторство —
[NOTICE](NOTICE.md).

## Время доставания основного оружия

Подгонка 2026-10-04 следует данным `blockfield_balance` серверного пака:
RO635 — 0,80 с; HK416 и Benelli — 0,90 с; AK-47, M4 и SKS — 0,95 с;
SPR — 1,00 с; M700 — 1,05 с; AWP — 1,15 с; M249 — 1,35 с.
AK-105 сохраняет исходные 1,29 с; пистолеты сохраняют быстрый переход.

Исходники — существующие JSON/OGG этого пака; для отсутствующего Benelli
взят опубликованный Elite X bf9 из серверного пина с проверенным SHA512.
Только `draw`/`draw_empty` и их временные эффекты масштабированы `scripts/animsync.py`
владельца Elite X. Draw-звук не растягивается (растянутый щелчок «провисал», владелец,
2026-10-05): это исходный звук, сдвинутый тишиной в начале на столько, на сколько позже
теперь встаёт на место корень модели (`root` дошёл до 15 % своего хода). Так зазор между
приходом оружия и щелчком остаётся авторским: AWP +0,36 с, M700 +0,33, M249 +0,24,
M4 +0,20, AK-47 +0,20, HK416 +0,17, Benelli +0,09, SPR +0,08, RO635 +0,05.
Все прочие клипы, кости и положения сохранены. Изменение этих defaults требует
согласованного обновления серверного датапака и клиентского ресурспака.

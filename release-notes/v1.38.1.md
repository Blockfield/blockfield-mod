# Blockfield/blockfield-mod v1.38.1

## Кратко

Единые градиентные силуэты снаряжения и видимая M18 в руках новой формы.

## Для игроков

- У оружия убрана угловая рамка; силуэты центрируются по видимому контуру,
  включая Glock с большим пустым полем в исходной текстуре.
- Нож показывает ∞. Нож, гранаты, аптечка, бронепластина, дроны и монитор
  получили чёткие сглаженные контуры с янтарным градиентом. У гранат видны
  рычаг и кольцо, у аптечки — ручка и медицинский крест.
- M18 больше не скрывается в перчатке: скорректированы хват и расстояние
  модели до камеры, включая удержание перед броском.

## Технические изменения

- Общая отрисовка силуэтов обрезает прозрачные поля; отдельные угловые
  компоненты рамки удаляются из HUD-текстур оружейных паков.
- Контуры расходников строятся из векторной геометрии вне экрана;
  сглаженная текстура кешируется для выбранного предмета. Перезагрузка
  ресурсов сбрасывает кеш. Рендер 3D-предмета и чтение GPU для HUD не нужны.
- Нативные счётчики патронов, резерв жилета, серверный бросок и дым M18
  сохраняются. Изменения ограничены клиентской отрисовкой.

## Обновлённые компоненты

Blockfield client 1.38.0 → 1.38.1. Сторонние моды и ресурсы не меняются.

## Совместимость и необходимые действия

Minecraft 1.21.1, протокол 2 и общий контракт паков прежние.
Сервер 2.60.4 с Blockfield server 1.38.0 совместим; обновление сервера
для этого исправления не требуется. Обновите клиент и перезапустите игру.

## Известные проблемы

Этот выпуск не исправляет шейдеры, FPS и остальные ограничения v1.38.0.
Игровая проверка выполнялась на Linux в Xvfb с software Mesa;
рендер на Windows и с Iris отдельно не проверен.

## Источники и ограничения полноты

Собственный headless-стенд, game-job `hud-consistency`, 2026-10-01:
проверены исходные дефекты и исправленный HUD оружия, ножа, M18, M67,
аптечки, бронепластины, RPG, дронов и монитора; масштаб GUI 2 и 3.
M18 проверена в покое, при удержании и отпускании: нативный use активен,
стек уменьшается с 2 до 1. Это не полная проверка всех вариантов cooking
и отмены. Проверки `just check`, `just test`, `just java-check` дополняют
игровые снимки; компиляция сама по себе игровой приёмкой не считается.

# Проверка homeserver, 8 сентября 2026

Источник: `ssh homeserver`, `docker logs b78dda4091da`, запуск 18:26:04–18:26:58
по времени лога. Сервер сообщил `Done` в 18:26:55. В сохранённом фрагменте
99 строк уровня ERROR и 33 строки WARN. Ниже — результаты диагностики,
не утверждение об устранении всех предупреждений.

## Кнопки меню — причина подтверждена, исправлен исходный код

В шаблонах konstaxa, baxmut, fields и kozyatyn командные блоки вызывают
`/menu class @p` и `/menu spawn @p`. Регистрация команд принимала только форму
без аргумента и требовала игрока в качестве источника команды.

На существующем локальном стенде `blockfield:konstaxa_1` проверена кнопка
`460 37 -268`: обычный ПКМ перевёл её в `powered=true`, а командный блок
`458 37 -268` записал в LastOutput ошибку разбора `@p`. Это соответствует
месту на пользовательском скриншоте; сбой бинда для этого случая исключён.

Добавлен одиночный аргумент игрока с правами уровня 2. Обычные игроки сохраняют
команды без аргументов. Обе формы используют прежние проверки состояния матча,
смерти и необходимости выбора класса. Набор тестов покрывает обе команды,
самостоятельный вызов, аргумент командного блока, адресацию игрока, запрет
непривилегированного выбора другого игрока и отказ от множественного селектора.

## Отдельные проблемы данных и запуска

| Сообщение | Найдено / дальнейшая проверка |
| --- | --- |
| `Failed to execute function blockfield:init` / `Chunk not there when requested` | Реальный сбой инициализации тира. Живая функция начинает с `forceload add -340 640 -320 641`, затем планирует пополнение. Стек проходит через установку принудительной загрузки чанка. ## Сообщения библиотек

97 из 99 ERROR — `No data fixer registered` для сущностей оружейных и декоративных
модов. Сервер после них продолжил запуск. Эти строки обозначают отсутствие схем
миграции сохранённых сущностей; они не доказывают ошибку создания сущностей и не
должны скрываться общим фильтром ERROR.

Оставшиеся WARN включают отсутствующие refmap, клиентские mixin targets на dedicated
server у Porting Lib/owo/SBW, необязательные классы интеграций, конфликт двух SlotAccessor,
рекомендацию Mod Menu, два подозрительных объёма жидкостей Create, предупреждения
offline-mode и один отставший тик запуска (2211 ms). Отдельно MineSkin пишет о работе
без API-ключа. По этому запуску нет основания обещать отсутствие функциональных
последствий всех этих предупреждений. Режим аутентификации и зависимости не менялись.

Изменения в этом наборе подготовлены локально. Живой homeserver и ранее запущенные
стендовые процессы не перезапускались; новая сборка в них ещё не проверена.

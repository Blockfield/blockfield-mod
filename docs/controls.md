# Управление Blockfield

Дефолты задаются клиентским модом, включая кнопку «Сбросить» в настройках управления.
Отличающиеся пользовательские бинды сохраняются. История применённых дефолтов хранится
в `config/blockfield-key-defaults.properties`: повторный запуск не должен отменять
переназначение обратно на старую клавишу. При первом переходе со старого пака привязки,
совпадающие с его дефолтами или исходными дефолтами модов, считаются неизменёнными.

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Shift, удерживать | Бег / быстрый бег ParCool |
| Ctrl | Присесть; смягчить приземление по правилам ParCool |
| Space | Прыжок, прыжок от стены, перелезание; подтянуться из зацепа |
| E, удерживать | Зацеп за край/перекладину, скольжение по стене, зиплайн |
| Z, удерживать | Лечь/ползти; на бегу — подкат; укрытие в блоке по контексту ParCool |
| C + направление | Уклонение на земле; бег вдоль стены в воздухе |
| ЛКМ / ПКМ | Стрелять / целиться; ПКМ без оружия — кнопки, двери и предметы |
| R | Перезарядить |
| F | Ближний бой |
| B | Режим огня |
| V | Кратность прицела |
| E | Взаимодействие TaCZ; посадка в технику |
| 1–9 / колесо | Выбор снаряжения; граната применяется после выбора её слота |
| Средняя кнопка мыши | Пинг / колесо пингов |
| Alt, удерживать | Голос рядом |
| Caps Lock, удерживать | Командная рация |
| Запятая | Отключить/включить микрофон |
| M | Планшет в руках: меню и карта боя (повторно — убрать) |
| ПКМ с поднятым планшетом | Режим курсора (мышь ведёт указатель, WASD по-прежнему ходит) |
| Esc с поднятым планшетом | Убрать планшет (меню паузы не открывается) |
| Ctrl + Tab с поднятым планшетом | Следующая доступная вкладка |
| Tab / Shift + Tab в меню или на высадке | Следующая / предыдущая доступная кнопка |
| Enter в меню или на высадке | Выполнить выбранное действие |
| PgUp / PgDn в длинном меню или на высадке | Предыдущая / следующая страница |
| Колесо на высадке | Листать страницы длинного списка классов или точек |
| Колесо или + / − на вкладке «Карта» | Приближение; при сильном приближении видны текстуры блоков |
| I / Tab / T | Инвентарь / список игроков / чат |
| N / K | ПНВ / тепловизор, если доступны в снаряжении |

В мастерской (карты Workshop) жезл выделения работает двумя кликами:

| Клавиша | Действие |
| --- | --- |
| ПКМ жезлом | Первый угол, повторная ПКМ — второй; живой бокс с размерами следует за прицелом |
| ЛКМ жезлом | Отмена незавершённого выделения или убрать готовое; жезл никогда не ломает блоки |
| Shift + колесо с жезлом | Двигать грань под взглядом (она подсвечена белым) |
| Shift + ПКМ жезлом | Личный буфер WorldEdit: copy/paste/rotate/undo/redo |

В технике: WASD, Space/Ctrl — движение, Shift — действие ускорения/задержки дыхания
соответствующего средства, C — сменить место, G — выйти, X — контрмеры, Q — захват цели.
Стрелки выбора боеприпаса/режима и вспомогательные команды техники остаются штатными.

Карта боя живёт на вкладке планшета (M), обзорная миникарта — своя, в левом верхнем углу HUD. При поднятом планшете стрельба, прицеливание, удар и применение предмета заблокированы;
попадание, Esc и повторное нажатие M опускают его.

Из дефолтов сняты редакторы, настройки модов, дубли карты/пингов, осмотр и модификация
оружия, вторая система ползания TaCZ, выбрасывание предмета и смена второй руки.
Это не отключает возможности модов: нужную клавишу можно назначить вручную.
Паркурные действия и параметры ParCool не отключаются. Автоматические действия и
комбинации без собственной клавиши, включая вертикальный бег по стене, сохраняются.

Повтор клавиши допустим для одного действия в разных системах (бег Minecraft/ParCool,
стрельба TaCZ/SBW), либо для предусмотренного контекста (уклонение на земле и бег по
стене в воздухе). Зацеп отделён от Space: ParCool ждёт новое нажатие прыжка, пока игрок
продолжает удерживать зацеп.

## AI-мастерская (инструмент AI в руках)

Экран AI: «Куда» переключает «На карту» (эскиз в текущем выделении) и «В библиотеку»
(размер W×H×D; «Размер: выделение» берёт габариты текущего выделения WorldEdit,
иначе 16×16×16; стороны 1..128). «Эскизы» открывает библиотеку: «Взять» кладёт эскиз
в руку, «Удалить» стирает. Каждый удачный результат сохраняется в библиотеку сам.

| Клавиша | Действие |
| --- | --- |
| ПКМ | Эскиз в руке: поставить на грань под прицелом (повторно — ещё раз); предпросмотр: построить; иначе — экран AI |
| Shift + ПКМ на предпросмотре или закреплённом эскизе | Взять эскиз в руку (призрак следует за прицелом до 64 блоков; мир не меняется) |
| ЛКМ с эскизом в руке | Убрать эскиз (предпросмотр на сервере живёт дальше) |
| R | Повернуть эскиз в руке на 90° (переназначается) |
| Колесо с эскизом в руке | Только высота эскиза (±1 за щелчок) |
| Shift + ЛКМ после постройки | Откатить последнюю постройку |

Контекстная панель сверху по центру показывает только действия текущего состояния
(покой, подготовка, эскиз в руке, предпросмотр, постройка, готово с откатом) с живыми
именами клавиш. Подготовка может идти минутами: экран можно закрыть, прогресс виден
в панели. Предпросмотр живёт, пока владелец онлайн в той же мастерской; постройка
старого эскиза сначала перепроверяет область.

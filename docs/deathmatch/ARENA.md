# Deathmatch: арена, правила, выпуск

Режим `deathmatch` (FFA) — `server/.../modes/deathmatch/DeathmatchMode.java` поверх ядра `DeathmatchRound`/`DeathmatchArena`.

## Как играется
- Хаб → меню → «Deathmatch: <арена>» (`play:deathmatch:<map>`). Кнопка есть только у карт с `supported_modes` = `deathmatch` без `campaign`; админ может `/bf start deathmatch <map>`.
- Нет карты, нет `deathmatch` в `supported_modes`, меньше 2 точек или нет эталона мира `maps/<id>/region` — отказ до открытия измерения.
- Подготовка → бой. Меньше `minimum_players` — подготовка начинается заново. Игроки без scoreboard-команд, глобальный friendly fire не меняется.
- Высадка: сервер выбирает безопасную точку (пол, свободные ноги/голова, без жидкости) дальше всех от живых противников; нет безопасной — игрок ждёт.
- Фраг только за смерть, принятую раундом (токен жизни); суицид и окружение — смерть без фрага. Reconnect сохраняет счёт, класс выбирается заново.
- Конец: лимит фрагов или время. Равенство лидеров — ничья. Итог сохраняется один раз (`Stats_Deathmatch_*.json`, экспорт с `winnerUuid`), затем комната закрывается и измерение удаляется. `/bf stop room <id>` — отмена без победителя. MMR режим не меняет.

## Правила: `blockfield/modes/deathmatch.json` (необязательно)
```json
{ "kill_limit": 30, "time_limit_seconds": 600, "preparation_seconds": 15,
  "minimum_players": 2, "respawn_seconds": 3, "protection_seconds": 2 }
```
Любое поле можно опустить — берётся значение по умолчанию. Невалидный файл — отказ открыть комнату.

Стартовая выкладка класса сохраняется целиком. Серия без смерти даёт одну аптечку за 2 фрага,
одну бронепластину за 3, а за 5 — аптечку, пластину и M67. Цикл повторяется каждые пять фрагов:
аптечки на 7/12/17…, пластины на 8/13/18…, полный комплект на 10/15/20… вплоть до конца матча.
Количество аптечек и пластин растёт с номером цикла: по две во втором, по три в третьем,
по шесть к 30 фрагам. Граната в комплекте остаётся одна.
Смерть обнуляет серию; сообщение показывает её фактическую длину, а не номер внутри цикла.

`streak_rewards` из [примера](deathmatch.example.json) заменяет всю таблицу. Записи с одинаковым
`kills` выдаются вместе; период повторения — наибольший `kills` таблицы. Настроенный `count`
аптечки или пластины умножается на номер цикла и ограничивается нативным размером одного
совместимого стака предмета; `count` гранаты не меняется. Сообщение берётся из первой записи
порога. Разрешены только
`superbwarfare:medical_kit`, `superbwarfare:armor_plate` и `lrtactical:throwable` с непустым
`throwable_id`. Граната требует аптечку или пластину на том же пороге. Оружие, патроны и
посторонние предметы в наградах запрещены; пустая таблица отключает награды.

Награды сначала дополняют совместимые стаки (включая тот же `ThrowableId` и размер стака
из выкладки), затем занимают свободные ячейки. Отличающиеся компоненты не меняются и не
сливаются. Остаток при переполнении выпадает у ног; существующая выкладка не вытесняется.

## Карта `dm_arena`
- Конфиг: `blockfield/maps/dm_arena.json` (копия — `docs/deathmatch/dm_arena.json`), в модпаке `server/lobby/blockfield/maps/`.
- Геометрия — блокаут 64×64: `dev/maps/build-dm-arena.py <dimension>` печатает RCON-команды `fill/setblock`.
- Сборка эталона на стенде:
  1. `mkdir -p <server>/maps/dm_arena/region` (пустой эталон), сервер запущен.
  2. `bf start deathmatch dm_arena`; имя измерения — в логе (`измерение dm_arena_N`).
  3. `execute in blockfield:dm_arena_N run forceload add -40 -40 40 40`, затем все команды скрипта через RCON.
  4. `save-all flush`, скопировать `world/dimensions/blockfield/dm_arena_N/region/*.mca` в `maps/dm_arena/region/`.
  5. `bf stop room <id>`. Измерение с forceload может остаться до рестарта — его удаляет `MatchWorld.cleanupStale`.
- Проверка точек появления без сервера: воксельная симуляция команд (все точки: пол твёрдый, ноги/голова свободны, внутри bounds).

## Выпуск на прод
Релиз модпака **не** обновляет эталоны карт (каталог шаблонов смонтирован в `/data/maps`, seed копируется только при пустом каталоге). Эталон арены ставится на прод на месте, между матчами (`rcon-cli list`, пустой `world/dimensions/blockfield`): `rsync` каталога `maps/dm_arena/` в каталог шаблонов. Конфиг `dm_arena.json` приходит с модпаком; без эталона кнопка открывает понятный отказ.

## Проверка на стенде
`dev/rig/dm-test.sh` (два клиента, `deathmatch.json` с `kill_limit: 3`, `preparation_seconds: 10`): отказ без карты, вход из хаба, высадка на разнесённые точки, фраг из оружия, респавн, суицид, reconnect, конец по лимиту, статистика, удаление измерения.

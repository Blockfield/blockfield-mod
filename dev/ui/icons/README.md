# UI icons

Lucide via [Iconify](https://icon-sets.iconify.design/lucide/), retrieved 2026-09-19. Upstream SVG geometry is unchanged; currentColor is resolved to white for runtime tint. See LICENSE (ISC and inherited MIT notices).

The client bundles 96×96 transparent PNGs under `assets/blockfield/textures/gui/icons`. Rebuild with ImageMagick: `magick -background none -density 384 input.svg -resize 96x96 output.png`. No network access or SVG library is needed at runtime.

Classes: assault → swords; marksman → focus; engineer → wrench; sniper → crosshair; FPV → drone.

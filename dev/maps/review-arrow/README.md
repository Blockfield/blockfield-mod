# Стрелка игрока

Ступенчатый треугольник заменён на авторский навигационный маркер: вырез у основания, светлая и янтарная грани, тонкий графитовый контур и слабая нижняя тень. Размер спрайта — 16 GUI-пикселей, текстура — 64×64 с линейной фильтрацией. Позиция и логика поворота сохранены; большой планшет использует тот же маркер.

[До / после](comparison.png). Реальные кадры тестового клиента, область миникарты увеличена в 3 раза без дорисовки.

Проверены трава, светлая и тёмная крыша, поворот на планшете, GUI scale 1 и 2. Клиентский JAR собран через `:client:remapJar`. Новая логика не добавлялась, меняется только рисование маркера.

Источник: [player-arrow.svg](../../ui/player-arrow.svg). Экспорт:

```sh
magick -background none -density 384 dev/ui/player-arrow.svg \
  -resize 64x64 -depth 8 \
  client/src/main/resources/assets/blockfield/textures/gui/player_arrow.png
```

# Чёткое увеличение карты

В `comparison.png` слева релиз 1.27.0, справа исправленный клиент. Это кадры отдельного тестового Minecraft-клиента на Anubis, одинаковый размер окна 1280×720, GUI scale 2, одинаковый масштаб и положение карты. Снимки обрезаны без изменения разрешения. Полные кадры: `before.png`, `after.png`; миникарта: `minimap.png`.

Причина размытия — линейная фильтрация увеличения. Для карты 123×150 блоков сервер передаёт 123×150 цветовых образцов, которые растягиваются примерно до 454×554 экранных пикселей. Теперь GL_TEXTURE_MAG_FILTER = GL_NEAREST; существующий линейный mipmap-фильтр уменьшения сохранён. Изменение применяется ко всем потребителям общих текстур карты и миникарты. Сглаживание отдельной стрелки не меняется.

Это исправление чёткости, а не добавление деталей мельче блока. Для реального увеличения детализации нужен рендер поверхностей блоков с текстурами: увеличение лимита MAX_SIDE или дублирование пикселей не создаёт новых данных.

Проверка: `:client:build` успешен, 136 клиентских тестов без ошибок; большая карта и повёрнутая миникарта проверены в отдельном тестовом клиенте. Проверены неизменность размеров карты и положения маркера. Тестовый сервер использует релизный серверный JAR 1.27.0; новая серверная логика не нужна. Изменение пока не опубликовано на прод.

# Загрузка карты

Реальные кадры отдельного тестового Minecraft-клиента:
- `tablet.png`: подготовка местности, Бердичев, 1280×720 / GUI scale 2.
- `spawn.png`: тот же индикатор на экране высадки; список точек и кнопка высадки доступны.
- `minimap.png`: исторический кадр первого варианта. По уточнению пользователя индикатор миникарты удалён: она полностью скрыта до готовности снимка.
- `ready.png`: готовая карта после завершения загрузки.
- `small.png`: планшет 640×360 / GUI scale 1, Anubis.

Сетка, мягкая сканирующая линия и движущийся сегмент обозначают подготовку сервером. После первого тайла показывается процент реально полученных уникальных тайлов; повторные пакеты его не увеличивают. Процент не изображает неизвестную длительность подготовки на сервере. Прогресс проверяется по ID, измерению и границам карты, как готовая текстура, чтобы при смене матча не показать чужую загрузку.

Общий компонент используется планшетом, высадкой и итогами матча. Пока изображение отсутствует, по пустому планшету нельзя поставить метку, а невидимые маркеры карты высадки не выбираются; список точек остаётся рабочим. Если сервер не обещает снимок и нет локального ресурса, отображается «Нет снимка карты» без вечной анимации.

Проверки: клиентская сборка, 136 тестов; дополнена проверка прогресса на дубликатах и полном наборе тайлов. В игре подтверждены подготовка, автоматический переход к готовой карте, компактный HUD и маленькое окно. Экран итогов и промежуточный процент отдельно на скриншот не пойманы. Изменения пока не опубликованы на прод.


## Уточнения после просмотра

Подпись заменена на «Проводится сканирование местности» (`tablet.png` обновлён). Высадка получила общую большую рамку, верхнюю панель с названием карты и отдельную боковую колонку. Индикатор занимает всю правую область, не сжимается до пропорций снимка. Готовая карта сохраняет соотношение сторон и координаты маркеров.

Актуальные кадры: `spawn-wide-scanning.png`, `spawn-wide-ready.png`, `spawn-wide-small.png` (640×360). Проверены переход к готовой карте и кнопка смены класса. Сборка `:client:build`, 136 тестов без ошибок; тест миникарты снова требует готовый снимок. Эти изменения ещё не опубликованы.
